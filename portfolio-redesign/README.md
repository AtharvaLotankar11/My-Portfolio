# How to apply
1. Close the dev server. Copy the `frontend/` folder from this zip over your project's `frontend/` folder (overwrite when asked). Your backend and all other files stay as they are.
2. `cd frontend && npm run dev` (no new packages needed; if three/r3f are missing run `npm install`).
3. Files replaced: index.html, tailwind.config.js, src/index.css, src/pages/Home.jsx, src/components/{Navbar,Hero,BuildingScene,About,Skills,Education,Experience,Projects,Certifications,Footer}.jsx, src/components/ui/*, src/Design_doc.md. New: public/fonts/*.
4. Not touched: Login, Register, OTP, MyMessages, MessageMe, CollaborateScene, auth, firebase, backend.
Note: the Gmail Summariser repo link was "#" in your data, so it shows greyed out until you add a URL (Projects.jsx).
